# E-Commerce Return Rate Reduction Analysis

##  Overview

This project analyzes e-commerce orders and product returns to identify factors affecting return rates and predict return risk.

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- MySQL
- Power BI
- GitHub

##  Objectives

- Clean and analyze order data
- Calculate return rates
- Identify return reasons
- Predict return probability using Logistic Regression
- Identify high-risk orders and products
- Build an interactive Power BI dashboard

##  Workflow

Raw Data → Python Cleaning → MySQL Analysis → Machine Learning → Power BI Dashboard

## Results

- Total Orders: **19,985**
- Total Returns: **2,810**
- Return Rate: **14.06%**
- High-Risk Orders: **1,112**
- High-Risk Products: **41**
